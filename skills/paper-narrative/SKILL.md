# paper-narrative — 论文叙事与论证

## 何时使用

把结果组织成论文/报告叙事，或修改引言、讨论、结论的论证链时。

## 结构

1. **问题**：现象、缺口、为什么现在重要。
2. **论点**：一句话主张；可被证据支持或反驳。
3. **证据**：每个主张对应结果/文献；区分描述、机制、因果。
4. **替代解释**：至少一个竞争解释及为何不成立。
5. **限制**：样本、测量、识别、外推边界。
6. **贡献**：理论/方法/经验贡献，不夸大。

## 写作规则

- 一段一个中心；首句给主张，后续给证据与限定。
- 不把“显著”当“重要”；不把“相关”当“因果”。
- 数字、单位、样本量前后一致；引用与参考文献一一对应。
- 中文学术写作保留作者声音，避免模板化空话；英文术语首次出现给中文并附原文。

## 硬约束

- 不编造结果、引文、审稿意见或数据。
- 不隐藏与主结论冲突的结果；写入限制或稳健性部分。
- 产出附 `artifact_id`、checksum 与 provenance；报告末尾列证据、未知、局限。
