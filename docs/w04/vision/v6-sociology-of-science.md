# v6 · 科学社会学：承认账、门的缺席与产能差额

> **维度**：科学社会学（默顿规范、优先权、信用循环、同行评审、排除机制）。
> **只回答一个问题**：谁被算作作者，谁被排除；"复核记录 + 无密钥哈希签名"在制度上能承担什么。
> **对象**：愿景三句——"人与 AI 共创共享知识 / 知识普惠 / 超越旧制度"。
> **证据基座**：`HEAD = 20a2df7`（2026-11-12）。`research-host` 的 `index.js`、`lib/store.js`、`lib/auth.js`；`docs/EVIDENCE-MODEL.md`；`README.md`；`CONTRIBUTING.md`；`git log`。
> **禁网声明**：默顿、布迪厄、拉图尔、哈德维希、阿罗引自记忆，只用于定位问题，不承担证据；未在仓内实测者标 `[THEORY]`，其余标 `[OBSERVED]` / `[INFERRED]`。

## 0 与 v1 / v2 的分工（先划清，避免三份文件说同一句话）

v2 立了**两本账**：因果账（"它怎么来的"）与支持账（"哪句话凭什么成立"）。v1 再立了**权利账与生产账**（`ledger.rights` / `ledger.producedBy`，附键不增第八面）。四本账都在记**产物**。

本文件主张：还缺一本**承认账**。它记的不是产物，是**两个主体之间的一次交换**：谁把什么交给谁、谁接受了、谁退回了、谁提出了异议。判据如下：

- **判据 A（信用是关系）** 默顿：发现只有在同行承认之后才成为发现，优先权之争即其证据。信用不是文件属性，是第二方给出、第三方见证的**归属判断**。
- **判据 B（场域分配）** 布迪厄：什么算"贡献"由场域内部标准决定，不由产物形式决定。同一份文件，署名不同，被读成"扎实"或"可疑"。
- **判据 C（信用循环）** 拉图尔与伍尔加：可信度→资源→数据→论文→更多可信度。**不能兑换的记录是死资产**。
- **判据 D（信任不可避免）** 哈德维希：没人能亲自验证他引用的全部证据。设计目标不是"人人可复核"，而是"**信任可被定位、可被挑战**"。

由判据 C：**若 `.science` 不是可兑换凭证，本地优先就是一种更安静的自我剥削。**

## 1 破坏（5 条，每条带证伪条件）

### D-01 账本记满了产物，没记过一次承认

**断言** 系统里没有一处记录"B 接受了 A 的 artifact"。没有接受，就没有信用；没有信用，其余四本账再厚也兑不出去。

**机制** `[OBSERVED]` 复核记录是 artifact 的**内部文件**（`reviews/<artifactId>.json`），它记录"一次判断"，不记录"一次交接"：没有 `recipient`、没有 `handoff`、没有"被谁采纳 / 被谁退回"。host 的 10 个工具里没有"请求复核 / 指派 / 队列"（已核：`research_project_*` / `artifact_*` / `provenance_get` / `review_*` / `science_*`）。RO-Crate 无 `author` 只是这件事的症状，不是病因——v1 D2 与 v2 EPI-02 已从权利与来源两侧记过这一点，此处不重复。

**为什么"再加一面"不解决** `[THEORY]` 七面是**物证面**，承认是**关系面**。关系面不能挂在单主体对象上；把 `author` 写成 artifact 的一个字段，只会得到"作者自称"（v1 D3 已证）。承认账的最小单位是一条**交换记录**：`(from, to, what, decision, at, why)`。

**证伪条件** ① 把一份 `.science` 原样存入公共仓库（OSF / Zenodo / 北大开放数据），**不手工补元数据**即得到带作者、可引用的 DOI；**或** ② 系统里存在一条"B 接受了 A 的 artifact"且 B 可被第三方识别的记录。二者满足其一，本条推翻。

### D-02 AI 的因果份额是唯一带隐私成本的面，因此最先被省略

**断言** 记录 AI 参与的那一面（`messages`）既是可选的，又是唯一会泄露私人过程的；于是它会被系统性地省掉——而任何建立在档案上的评价装置，都会因此**奖励不披露**。

**机制** `[OBSERVED]` `research_artifact_record` 的 `messages` 是 `Optional session/message anchor`；缺省即 `unavailable`。七个面里，`code` / `log` / `environment` / `literature` 都可以是中性技术字符串；`messages` 是唯一会把"我当时的犹豫、错误提问、被否决的方案"一起交出去的面。v2 T3 已立"归因≠归责、AI 有因果份额无断言地位"；本条目只加一句制度后果：**归因数据一旦有隐私价，理性作者就会第一个删它，于是"AI 参与率"永远不可知。**

**为什么不能靠"自愿披露"修** `[THEORY]` 披露的收益（更可信）是公共的、延迟的；成本（暴露过程）是私人的、即时的。这在任何评价装置里都会产出同一个均衡：**人人少写一句，档案整体失真**。而这恰好发生在本项目最想承重的那个领域（评价与可识别性）。

**证伪条件** 在一个真实课题组里统计 20 个 artifact：带 `messages` 面（`status: available`）的比例 **≥ 80%** 即推翻（说明披露成本不构成系统性筛选）。

### D-03 没有门，所以谈不上"绕过"：复核在系统里只是一次自签写入

**断言** "评审被绕过后的责任真空"这个提法预设了一道门。现状是：**系统里没有"门"这个对象**——所以真空不是事故，是常态。

**机制** `[OBSERVED]` 复核 = 往 `reviews/<artifactId>.json` 追加一轮并自签 `sha256(字段)`；无密钥、默认无身份（`RESEARCH_REVIEW_AUTH=off`）、`authority:'author'` 合法（`REVIEW_AUTHORITIES`）。`research_review_verify` 自己写着："the round file is not a Merkle log, so deleting the earliest rounds cannot be detected from the file alone"。所谓"绕过"需要绕过一个拒绝你的东西；这里没有任何东西会拒绝。v1 D3 从"认证回到名字"讲，v2 EPI-03 从"复核不是反驳通道"讲；本条目只补最硬的一环：**档案离开文档后不携带告诫**——`science-manifest.json` 只有 `format/project/createdAt/readOnly/files`，RO-Crate 的 `Dataset` 只有 `name/description/hasPart`，没有 `limits`、没有 `review.relation`。

**读者看到什么** `[INFERRED]` 并置 `"decision":"accept"`、`"valid":true`、`"signatureValid":true` 三个肯定词，没有一个含"这是谁说的"。界面可以改（HCI-02 已提），**档案不会自己改口**。

**证伪条件** 找一份 `.science`，其内机器可读元数据能告诉陌生读者"这条复核是自审、未校验身份"。找到即推翻。

### D-04 准入成本分层：马太效应落在名字上，不在对象上

**断言** 对象层面的中立（哈希面前人人平等）买不到信用层面的中立；同一份 artifact，署名不同，被接受的概率不同，而工具对此完全沉默。马太效应不需要恶意，只需要一个朴素事实：**可识别的名字更省审阅成本**。

**机制** `[OBSERVED]`
- 导出对单条目 **≥ 2,097,152 B** 直接抛 `tar entry is too large`（`buildTar()`，已记为 ALG-04）：一份 2 MiB 以上的访谈转录、扫描件或数据集**可记录、可列出，永远导不出**。
- 阅读路径依赖外部 Docling：同两页 fixture 实测 **115 s / 317 s**，首次转换还要联网拉模型（W03-GAP-MATRIX，ENV-02）。
- 唯一的"已验证身份"路径是 `oidc`，需要机构 IdP；v1 §5 已自陈这会"把已存在的学术等级技术化"。

**被排除的三种人** `[THEORY]` ① 时间少的人（本科课堂、教学负担重的教师）；② 质性 / 田野研究者：证据超重、难脱敏；③ 无 IdP 的独立研究者。v2 EPI-04 已指出 schema 的形状偏向计算实验室；本条目加的是**分布后果**：准入成本 = meta 劳动 + 算力 + 机构身份，三者都按既有资源分配。

**证伪条件** ① 一个不做代码的质性项目（含 ≥2 MiB 材料）只用受支持路径产出完整公开包，无需手工绕行；**或** ② A/B 测试：同一 artifact 分别挂"有名"与"无名"作者，送 5 位本地同行，接受率无显著差异。任一成立，本条推翻。

### D-05 承认端产能固定：生产爆炸的差额转给最弱的一方

**断言** AI 把 artifact 的边际成本压到接近零，但**承认**仍要一个人的时间；差额不会消失，只会转移。

**机制** `[THEORY]` 默顿的组织化怀疑是一种**劳动**，不是一种态度：读、判、写理由、回信、承担后果。生产端指数增长、承认端线性不变，制度只能配给。三种配给方式里，前两种在仓内已有对应：**作者自审**（`authority:'author'` 合法，D-03）、**评审通胀**（门槛提高，用"看名字 / 看机构"筛，D-04）；第三种**无偿劳动转移**（初阶者承担更多评审）在仓外发生，但 v2 T5 的"未核验污名"正落在这一环。

**为什么工具加速的是错的那一端** `[OBSERVED]` 10 个 host 工具里没有一个降低复核成本：没有请求、没有队列、没有"待我复核"的列表。工具让产出更快，让复核保持手工。

**证伪条件** 在一个真实课题组里量 14 天：`artifact 记录数 / 由他人写的复核轮数`。若比值 **≤ 1**（每个 artifact 至少一次他者复核）且稳定，本条推翻；若该组反馈"有了记录后被要求评审的次数上升"，同样推翻。

## 2 理论构型（5 条原则，附与 v1 / v2 的冲突点）

### P1 承认账的单位是"交换"，不是字段

每条主张要有一个**担保人**（guarantor），并留下"接受 / 退回"的痕迹；贡献声明区分提出 / 执行 / 复核 / 否决。
*与 v1*：v1 T3 要把认证外挂给可追责机构（issuer > signature）。方向一致，但不重叠：机构认证回答"谁签的"，不回答"谁被谁接受了"。二者必须都有，缺一个就只剩自述。
*与 v2*：v2 T3 要求"可回应通道"。本原则把它具体化为记录单位：**没有接收方，就没有可回应**。

### P2 "已复核"是关系谓词，不是签名事件

组织化怀疑要求一个**有能力的、非作者的他人**。三条硬约束：`reviewer ≠ author`；异议须可被**他人**追加；"reviewed"一词只在 `other + verified` 时可用，否则一律写 `self-attested`。
*与 v1*：v1 T3 关心 issuer 是否算数；本原则关心**谓词是否被滥用**——签名再强，若作者自签也叫 review，制度就空了。
*与 v2*：v2 T4 要求分歧可见；本原则给出可见的最小条件（谁能追加、词怎么用）。

### P3 记录必须有边界：后台权

科学在**后台**完成：失败的试点、半成品、私人判断。一个"全记录"的系统取消后台，从而改变它记录的行为——**观察者效应发生在制度层**。所以原则不是"全部公开"，而是：**可以不公开，但必须声明"我没有公开什么、为什么"**，且声明可被他人异议。
*与 v2*：v2 T5 说永久 `unavailable` 标记会变成认识论污名；本原则把它推进一层：**永久可见**同样会改变行为，只是方向相反（少冒险、少写、少试）。
*与 v1*：阿罗的信息悖论——知识一经披露即失去独占价值。自愿披露会被竞争吃掉，"保留权"会变成"隐藏权"。这个冲突只能由制度（资助方 / 期刊的强制存缴）解决，工具不能。
*与产品人格*："证据优先"的自我形象与"我有权不给你看"冲突。这条原则要求产品学会说"不给"。

### P4 公地是关系，不是仓库

一个对象只有在**别人能用、且能反驳**时才算共享。普惠的指标是参与成本（时间、算力、语言、身份门槛），不是文件的免费。
*与 v1*：v1 T2 说"开放许可 ≠ 公共性"，并从物质条件论证；本原则从参与关系论证，结论一致而理由不同——两者叠加才够。
*与 v2*：v2 的公地是最大可核查性；本维度还要加"**被允许公开地犯错**"。

### P5 承认不可由工具授予，只能被预备

工具能生产的是**前承认对象**（pre-recognition object）与一份备好的卷宗；授予发生在场域里（期刊、学会、课程、评审集体）。把"超越"写成交付物，等于替场域提前宣布结果。
*与 v1 的收敛*：v1 T4 从成本侧得到同一结论（三功能分别找承接者，别宣称已超越）；本维度从授予侧得到它。**两个独立维度收敛到同一句，说明这不是口味问题。**

## 3 实践方案（4 条最小机制）

> C 级沿用本仓口径：**C0** 纯文本 / 约定（0 行代码）；**C1** 单点改动、可一 commit 回退；**C2** 新记录类型或跨插件协议、需迁移兼容；**C3** 依赖库外参与方，不能单方交付。成本按人日。

### M-01 贡献者块 + 担保人（C1 · 0.5–1 人日）

- `project.json` 增 `contributors[]`：`{id, role: proposed|executed|reviewed|vetoed, scope, ai: none|assisted|generated}`；artifact 记录增 `guarantor`（单数、必填、可后补）。
- 与 v1 P1 的 `ledger.producedBy` 分工：那记"谁付的钱、用的什么模型"，这记"**谁为这句话负责**"。一个都不能少，但不能合并。
- `.science` 的 RO-Crate 补 `author`、`license`、`datePublished`（v1 P1 已给注入条件：仅当 `available` 才写，不编）。
- **最小可验证实验**：两人合作一个真实项目，仅凭记录回答"谁为第 3 节负责"。5 位冷读者独立判断，**≥4 位指向同一人**为通过；只能说出项目名为失败。失败即说明"加字段"解决不了承认（回到 D-01）。

### M-02 他者标记 + 自审降级 + 机械检查器（C1 · 0.5 人日）

- 复核轮增 `relation: self|other`（由 `reviewer` 与 `guarantor` 是否同一人推出，**不靠自填**）；`verified` 沿用 `auth.verified`。
- 任何 UI 与导出文案："reviewed" 仅当 `relation=other && verified=true`，否则 `self-attested`。
- 附约 30 行 `check-archive.mjs`：读 `.science`，遇 `decision=accept && relation=self` 报 `SELF-ATTESTED` 并非零退出。
- **最小可验证实验**：造 5 份归档（2 自审、2 virtual 他者、1 留空），三人各跑一遍。**3/3 全部分类正确**为通过；把自审读成"已复核"为失败。
- 这同时是 v1 P3（issuer 信任）与 v2 T4（分歧可见）的前置：**谓词不先分清，后两者都落不了地**。

### M-03 异议日志 + 可选见证（C2 · 2–3 人日）

- `objections/<artifactId>.jsonl`，每行 `{prev, artifactId, claimRef, by, at, reason, sig}`，`prev` 为上一行哈希——库内可检的迷你透明度日志。
- 任何人（含读者）可追加；作者删不掉（删除即断链）。
- 与 v1 P4 分工：v1 的锚证明"**我先**"，本日志证明"**我反对**"。合起来才是承认账：接受 + 异议。
- `witness`：把末行哈希写进用户选定的外部通道（git commit body / 公开仓文件 / 发给自己的一封邮件）；无见证时所有输出必须标 `unwitnessed`。（**C2 是因为默认可无见证；若把见证设为强制，则升 C3——那时交付依赖库外参与方。**）
- **最小可验证实验**：三种篡改——删中间行、改末行、整文件替换。**有见证时 3/3 检出；无见证时整文件替换 0/1 检出，并如实报 `unwitnessed`。** 数字照抄进文档，不修边。

### M-04 选择性披露包（C2 · 1–2 人日）

- `research_bundle_public` 产出三层：T1 主张 + 定位符 + 限制 + 复核关系；T2 各 artifact 的 checksum 与面清单；T3 全量 payload。
- manifest 增 `limits: []`（**必须非空**）与 `disclosure: {withheld: [{what, why}]}`；内嵌 `review: {relation, verified, witness}`。
- **最小可验证实验**：只发 T1 给 6 位冷读者，问两句："这条主张的凭据是什么？""哪些东西**没有**被检查？"**≥5 位能说出至少一条限制**为通过；把 T1 当成"已认证"为失败。
- 第二实验：让一位读者从 T1 过度推论，`limits` 块应能在一分钟内反驳他。做不到，说明限制写得像免责声明，不像证据。

**不做清单**：信誉分 / 影响力指数；区块链；DOI 铸造；强制公开存缴（政策斗争，不是插件）；"AI 共同作者"标签。

## 4 冲突台账（对准 v1 / v2 的既有条款）

| 议题 | 本维度（科学社会学） | v1 政治经济学 | v2 认识论 |
|---|---|---|---|
| 私有默认 | 对竞争性信用制的**准确**反应；工具改不了 | T2：开放许可 ≠ 公共性；需供给者 | 最大可核查性 |
| 责任单位 | 担保人（可答责的最小单位） | T3：issuer > signature，外挂机构 | T3：可回应通道，非字段 |
| 披露 | 有权保留，但须声明（P3） | 保留权会被竞争吃掉 → 需强制 | T5：未核验不可永久污名 |
| 公地 | 参与成本 + 公开犯错权（P4） | 物质条件 + reciprocity（T5） | 可核查性 + 分歧可见（T4） |
| "超越" | 范畴错误：承认由场域授予（P5） | T4：三功能分找承接者，别宣称 | — |

三处**不可同时满足**：强制存缴 vs. 保留权；个人担保 vs. 结构性归责；最大可核查 vs. 后台权。愿景必须显式选边，否则三句话互相拆台。

## 5 自攻击

这份文档本身是它所批判条件的产物：禁网、无田野、无 IRB、一人执笔，而且不会署我的名。若 P1 成立，它自己就是反例——一份无法指派担保人的批评。可辩护的只有一点：它把证伪条件写在每条断言旁边，**读者不需要相信作者就能否证它**。这正是本维度希望 `.science` 具备的性质：不是让人相信，而是让人能反驳。
